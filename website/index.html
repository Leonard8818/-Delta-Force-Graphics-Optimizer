它会做什么

  • 30 多项 Windows 层优化：电源计划深度定制、进程与 IO 优先级、显卡中断绑核、系统精简、显卡层设置
  • 三套预设方案可选，也可以逐项勾选，或存成自己的方案
  • 解决掉帧专项（实验功能）：清理 DirectX 与显卡驱动的着色器缓存，针对游戏更新后「每隔十几秒卡 2~3 秒」的症状
  • 自动寻找最佳配置 Beta：在同一台电脑的固定场景中反复对比低风险方案，变差或没有明确收益时自动定向回滚
  • 三项硬件体检（只读不改）：PCIe 链路带宽异常、VC++ 运行库缺失、内存没开 XMP/EXPO
  • 附带头部主播的游戏内画质设置参考，省去自己到处搜的功夫
  • 不修改游戏安装目录内文件，仅调整 Windows 和显卡相关系统设置

下载前请知悉

  • 本工具没有购买代码签名证书，Windows 会提示「未知发布者」，需要点「更多信息 → 仍要运行」。
  • 因为要修改注册表和系统服务，部分杀毒软件可能误报，介意请勿使用。
  • 所有改动在写入前都会备份到 backup 目录，界面上点「撤离还原」即可完整回退。
  • 同意使用声明后会发送匿名版本、硬件概况、启动/优化/还原汇总及粗粒度优化强度；不发送具体勾选项、自存方案名称、用户名、机器名、游戏路径或诊断日志，可在本地配置中停用。
  • 优化效果因机器而异，不保证一定涨帧；建议改完自己实测对比。
