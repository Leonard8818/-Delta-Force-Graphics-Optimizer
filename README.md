# DeltaForceBooster — 三角洲行动一键画面优化 v0.12

抖音教程里那些一步步改电脑设置的帧率优化，这个工具一键做完：
检测你的硬件 → 勾选优化项 → 一键应用（自动备份）→ 随时一键还原。

## 安装

- **安装版 `DeltaForceBooster-Setup-vX.Y.exe`（推荐）**：双击后是图形安装向导，可自选
  安装位置——默认装到你的「下载」文件夹（就算被移动到别的盘也能正确定位，无需管理员
  权限），选择 Program Files 等受保护目录时会自动检测并引导提权，绝不默默失败；
  位置页显示所需空间与目标磁盘剩余空间。**装在下载文件夹的提醒**：Windows「存储感知」
  可配置为自动删除下载文件夹里长期未打开的文件，也有人定期手动清空这里——程序连同
  安装目录内 `backup\` 的系统还原备份会一起丢；长期使用建议在位置页换个目录（向导会
  就地金色提示，但不阻止安装）。装完自动创建
  开始菜单「三角洲行动优化助手」「卸载优化助手」快捷方式，可勾选「立即运行」。
  **覆盖安装保护**：目标目录里已有的 `profiles\`（自存方案）、`backup\`（系统还原备份）、
  `config\`（运行状态）不会被覆盖或删除。完成页可勾选**创建桌面快捷方式**（默认勾选），
  卸载时会一并清理。
- **绿色版 `DeltaForceBooster-Portable-vX.Y.zip`**：解压到任意目录，双击「启动优化工具.exe」
  即用；不想要了直接删目录（`backup\` 按需保留）。绿色版没有安装过程，建议右键
  「启动优化工具.exe」→「发送到 → 桌面快捷方式」，免得关掉后找不到入口。

## 普通用户：图形界面

双击 **`启动优化工具.exe`**（会请求一次管理员权限，属正常——电源计划和 HAGS 是系统级
设置）。exe 由系统自带编译器构建、无第三方依赖，不闪黑框，也不受 PowerShell 执行策略
限制；`启动优化工具.bat` 保留作为后备入口，效果相同。

界面分两个标签页：

- **优化**：显示你的 CPU/显卡/内存、自动找到的游戏路径（多路查找：运行中的游戏进程 →
  卸载注册表 → WeGame/Steam 平台目录 → 各盘符常见位置兜底，装哪都能认出来）、每个优化项
  的当前状态，勾选后点「执行优化」；列表顶部有三态全选框，一键勾上/清空全部**可执行**
  的项（已就绪的不重复执行）。执行期间有进度条显示当前项和 `第 n / 共 m 项`，每项
  结果实时写入运行日志，结束后给出明确的完成度结论（如「共 30 项 — 27 成功、1 失败、
  1 跳过、1 项体检发现问题」），失败项单独列出——纯检测项查出的问题按金色「提示」单独
  归类，不会混进「失败」，并弹出「体检发现问题」对话框：逐条给出教程（VC++ 运行库怎么
  覆盖安装、XMP/EXPO 怎么进 BIOS 开）和**可点击的微软官方下载按钮**（链接为代码内硬编码
  常量、仅浏览器打开、工具自身绝不下载执行）；检测项行内也有「解决办法」按钮直达同一
  对话框。「显卡指引」弹窗顶部醒目标出检测到的显卡型号（双显卡说明以独显为准），并按
  型号标注 DLSS/FSR/XeSS/Reflex/Anti-Lag 各自适用哪些卡。执行完成后若有需重启才完全
  生效的成功项（电源计划、HAGS、MPO、
  服务禁用等），会弹醒目的「需要重启电脑」提醒，列出等重启的项，可选「立即重启」（二次
  确认后才执行）或「稍后自己重启」。「还原设置」同样是逐项进度反馈，完成后弹窗告知还原
  了多少项、用的哪个备份文件；「继承默认」的电源隐藏项因系统 ACL 无法删键时，会自动改用
  powercfg 写回方案默认值，写不回且残留在工具自建方案里的按「跳过（无实际影响）」单列，
  不再误报还原失败。运行日志区有一键复制小按钮，反馈问题时把日志整段拷给别人不用手动
  拖选。检测到新版本时标题栏会亮起「有新版本」入口（启动时查一次，运行期间每 30 分钟
  静默复查，长期挂着也不用重启软件才看到）；点开更新说明后可「立即更新」——应用内下载
  安装包（进度条、可取消），下载源锁定官方域名白名单，完成后强制校验 SHA256 与文件大小，
  校验通过才会提示关闭本程序并启动安装器，任何一步失败都退回「浏览器打开下载页」。
  下载与安装永远由你点击触发，不做静默后台安装。绿色版用户同样走安装器升级：把安装位置
  选到现在的目录即可原地更新，自存方案 / 备份 / 运行状态不会被覆盖。
- **主播设置参考**：昊天、林树、mad98 等头部主播的游戏内画质设置对照表（含硬件配置和
  来源链接），已按游戏内「设置 → 画面」的菜单分组展示（显示设置 / 战斗视角 / 基础画质 /
  高级画质 / 超分辨率，分组依据公开攻略整理、个别项位置可能随版本调整），照着表能逐个
  菜单找到每一项。**纯参考页面——本工具不会也无法修改游戏内设置**，请进游戏手动对照
  调整；主播设置随版本/硬件而异。数据在 `data\streamer-settings.json`（分组信息在
  `settings_schema` 的 `group` 字段，老格式数据自动归入「其他」），缺失时页面会提示
  「数据尚未就绪」。

## 下载后脚本被拦怎么办

从网上下载解压的文件带「来自 Internet」标记，部分机器的执行策略会拒绝运行未签名
.ps1（报「未对文件进行数字签名」）。三种解法任选：

1. **用 `启动优化工具.exe` 启动**（推荐）——exe 不受执行策略限制，内部已带豁免参数；
2. 解除文件标记：管理员 PowerShell 里 `Unblock-File -Path .\* -Recurse`（或对单个文件）；
3. 手动运行脚本时带上豁免参数：`powershell -NoProfile -ExecutionPolicy Bypass -File <脚本>`。

## 优化没生效？跑诊断脚本

某项优化执行后仍显示「待优化」时，用管理员 PowerShell 运行：

```
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\diagnose.ps1
```

它会打出全部电源方案的原始名与解析名、模板激活自检、四个隐藏电源项的真实写入自检
（写完立即还原、不留改动）、所有优化项的当前判定，把完整输出复制反馈即可定位问题。

## 关于电源计划的命名

系统里没有可直接激活的「卓越性能」方案时，工具会用 `powercfg -duplicatescheme`
实例化一份并命名为 **「三角洲优化 · 卓越性能」**（GUID 记录在 `config\`，重复执行只会
复用不会堆积）。「还原设置」会把活动方案切回原来的，但**保留**这份工具创建的方案
（你可能已在用它）；不需要的话在控制面板→电源选项里手动删除即可。

## AI 助手：通用技能

把整个文件夹发给/指给任意 AI 助手（Claude Code、Codex、WorkBuddy、豆包电脑版等），
让它阅读 `SKILL.md` 按流程执行。Claude Code 用户可把本文件夹复制到
`~/.claude/skills/delta-force-boost/` 注册为正式技能。

命令行直接用：

```
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\delta-booster.ps1 -Detect
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\delta-booster.ps1 -Apply
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\delta-booster.ps1 -Restore
```

## 预设方案

不想逐项勾选就直接套方案（`-ListPresets` 可查看）：

| 方案 | 内容 | 适合 |
|---|---|---|
| `felix` 费利克斯路线（主推） | 30 项全套，按费利克斯Fx 的调试顺序：电源深度定制→进程/IO 优先级→中断绑核→系统精简→显卡驱动层。代价：鼠标手感变直、休眠/快速启动没了、系统搜索变慢、待机功耗升高 | 愿意按博主整套抄作业的人 |
| `balanced` 均衡推荐 | 20 项，收益明确、副作用小：不改桌面外观和鼠标手感、不禁用服务、不动休眠 | 绝大多数人 |
| `safe-only` 保守 | 7 项，只改当前用户设置、不碰系统全局、不需重启 | 公司电脑或不想动系统 |

也可以把自己的搭配存成方案：`-SavePreset "我的方案" -Items dvr-off,wer-off`，
存在 `profiles\` 目录里，之后 `-Apply -Preset 我的方案` 直接套用。

## 优化内容

Windows 层（可自动，共 32 项，按费利克斯Fx 的调试链路组织）：

- **① 电源**：卓越性能计划、隐藏项深度调优（USB3 链路省电关闭、处理器性能时间检查间隔
  拉到 5000ms、大小核调度强制走高性能核、关电源节流）、锁定电源计划防游戏篡改
- **② 调度/优先级**：Win32PrioritySeparation=40、游戏进程 CPU/IO 优先级提到「高」、
  MMCSS 系统响应度=0、MMCSS 游戏任务档位拉满、解除多媒体网络限流、内核代码常驻内存
- **③ 中断绑核**：独显中断固定到最后一个 P 核（避开 CPU0，微软官方 Affinity Policy
  注册表机制，不依赖第三方工具；读不到核拓扑时自动不可用）
- **④ 系统精简**：关 Xbox 录制、关错误报告、关透明特效、关内存压缩（32G 以上才默认）、
  禁用 MPO 多平面叠加、禁用 SysMain/Windows Search 服务、关休眠与快速启动、
  禁用动态计时器（bcdedit）
- **⑤ 显卡层**：HAGS、为游戏禁用全屏优化、强制独显运行、禁止显卡动态降频（锁 P-State）、
  关闭 NVIDIA App「自动优化游戏设置」（它开着会把 NVIDIA 认为"最佳"的画质写进游戏、
  覆盖你手调的参数；改动前备份整个配置文件，还原时逐字节写回）
- **纯检测（只读不写）**：PCIe 通道体检（插错槽/劣质延长线导致的 x8/x4 直接报警）、
  VC++ v14 运行库冲突体检（版本错乱是掉帧闪退的常见原因，只提示不代劳卸载）、
  内存 XMP/EXPO 体检（没开就是白丢几十帧，但 BIOS 只能你自己进）
- 可选不默认（副作用或结论有争议，须明确知情）：视觉效果最佳性能、关闭鼠标指针精确度、
  关闭「窗口化游戏优化」、虚拟内存固定为内存×1.5~×2（仅闪退时用）

> **v0.6 移除了「关闭引导虚拟化」**：三角洲更新后 ACE 反作弊已开始检查 CPU 虚拟化状态，
> 关掉会导致游戏弹错误进不去。这项收益本来就小，不值得冒这个险。已经用旧版关过的用户，
> 用「还原设置」仍可正常回滚。

显卡驱动层（半自动）：按你的显卡（N 卡/A 卡/Intel）生成精确的手动设置清单。
`tools\` 已附带按费利克斯参数生成的 `DeltaForce-Felix.nip`（最高性能/超低延迟超高/
垂直同步关/预渲染 1/着色器缓存无限制/线程优化开/DLSS Preset K）；再把 NVIDIA Profile
Inspector 放进 `tools\` 即可一键导入——导入前请先在 Inspector 里导出备份当前配置。

## 安全说明

- 每次优化前，所有被改动的注册表值、电源计划和配置文件（NVIDIA App 那项存整文件原始
  字节）都会备份到 `backup\`，还原按备份逆序恢复。
- 只改 Windows 系统设置、游戏 exe 的兼容性标记与 NVIDIA App 的自动优化开关，
  **不碰游戏安装目录内任何文件**，无反作弊风险。
- 不采集、不上传任何数据，全部本地运行（检查更新时只请求官方服务器上的版本清单）。
- 内置更新只允许从官方域名（df.ltz88.cn）经 https 下载，下载完成强制校验清单声明的
  SHA256 与文件大小，任一不符立即删除、绝不执行。如实说明局限：这能防传输途中被篡改，
  防不住官方服务器本身被攻破（详见 `build/README.md` 的发布说明）。
